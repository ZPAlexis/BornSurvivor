# Born Survivor

**The second demo Unity game with a "Pick 1 of 3" rogue-like style mechanic. Inspired by the game Vampire Survivors.**

The player survives for as long as possible while increasingly difficult waves of enemies spawn every few seconds. The focus was the "Pick 1 of 3" mechanic, a choice of one of three power-ups drawn at random from a longer list, and the complexity that comes with it.

**[Read the case study](https://acoelho.dev/en/projects/born_survivor)** · [Playable Windows build](https://github.com/ZPAlexis/BornSurvivor-V0.1.0-PC-Demo)

> **Archived:** a finished learning prototype. It was one of the opportunities I took to turn a long-standing interest in game design into hands-on practice, enriching the foundation of the gamified products and experiences I build today.

Built with Unity 2021.3 and C#.
